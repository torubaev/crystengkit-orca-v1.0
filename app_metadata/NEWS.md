# CrystEngKit-ORCA news

## Version 1.1.18 — August 29, 2026

CrystEngKit-ORCA 1.1.18 expands TD-DFT workflows and improves calculation reliability, portability, and visualization.

### What is new

- Complete, restart-safe TD-DFT/TDA absorption and emission workflows with explicit geometry and wavefunction handoffs.
- Improved TD-DFT post-processing, root selection, NTO generation, spectra, and visualization controls.
- MPI-aware ORCA setup with safe serial fallbacks and adaptive process and memory defaults.
- A more responsive Builder during calculations, with clearer monitoring and failure diagnostics.
- Consistent molecule styling and rendering across PyVista-based viewers.
- Improved Linux portability, packaging validation, and application metadata handling.

### Installation

Download either installer from the [v1.1.18 release page](https://github.com/torubaev/crystengkit-orca-v1.0/releases/tag/v1.1.18):

- The full installer contains the application files.
- The web installer downloads and verifies the matching full installer.

Projects and user settings are preserved when updating an existing installation.
